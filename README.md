# Прокляття Онлайн

Адаптивна версія сторінки за наданими референсами.

## Структура
- `index.html` — повністю самодостатня сторінка з HTML/CSS/JS.
- Дизайн адаптований під ноутбук і телефон.
- Головний екран + екран ритуалу.
- Вбудовані SVG-візуали, тому сторінка не залежить від зовнішніх зображень.

## Запуск
Відкрийте `index.html` у браузері або віддавайте його як статичну сторінку через будь-який вебсервер.
